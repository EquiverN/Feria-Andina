# Feria Andina - Instrucciones para agentes de IA

## Proyecto

Feria Andina es una plataforma de comercio para la cooperativa
Manos de la Quebrada, desarrollada por Cardón Software.

## Stack tecnológico

- Frontend: React, TypeScript y Redux Toolkit (`web/`).
- Backend: Node.js y Express (`api/`).
- Base de datos: PostgreSQL.
- Testing: Vitest.
- Control de versiones: Git y GitHub.

## Comandos

Ejecutar desde la carpeta del componente correspondiente:

- `npm install`: instalar dependencias.
- `npm test`: ejecutar pruebas.
- `npm run lint`: revisar el estilo del código.
- `npm run build`: compilar el proyecto.

Utilizar los comandos cuando estén configurados en package.json.

## Convenciones

- Utilizar TypeScript en modo estricto.
- No utilizar el tipo `any`.
- Utilizar nombres descriptivos.
- Usar nombres del dominio en español: producto, pedido, carrito.
- Escribir código claro, modular y mantenible.
- Mantener los tests actualizados.
- Utilizar Conventional Commits: feat, fix, docs, test y chore.
- Escribir los mensajes de commit en español.

## Restricciones

- No agregar dependencias sin autorización.
- No leer ni modificar archivos .env.
- No exponer credenciales ni datos personales.
- No modificar la estructura de carpetas sin autorización.
- No realizar cambios ajenos a la tarea solicitada.
- No realizar commits ni push sin autorización.

## Flujo de trabajo

- Analizar el contexto antes de modificar código.
- Explicar las modificaciones realizadas.
- Ejecutar las pruebas disponibles.
- Informar errores y limitaciones.
- Dejar la aprobación final al desarrollador.
